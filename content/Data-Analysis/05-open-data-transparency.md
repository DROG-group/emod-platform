## Purpose

You'll learn how open data enables accountability—and its limits.

---

## Scenario

You need to verify a claim about government performance. Open data should help. You need to find and evaluate the right data source. You have:

- **Time available**: 30 minutes to find and assess data
- **Stakes**: Claims about public institutions should be verifiable
- **Data access**: Public data portals, official statistics
- **Constraint**: Data availability varies; not everything is open

---

## Task

Produce three outputs:

1. **Assessment**: Is the relevant data available and reliable?
2. **Confidence level**: Low / Medium / High
3. **Next action**: Use the data, seek alternatives, or acknowledge limitation?

---

## Method: Open Data Evaluation

### Start here: Identify data needs

- What specific data would answer the question?
- Who would collect this data?
- Is it likely to be public?

### Step 2: Find authoritative sources

- Official government statistics portals
- International organisations (WHO, World Bank, etc.)
- Academic data repositories

### Step 3: Evaluate data quality

- Methodology documented?
- Updated regularly?
- Known limitations acknowledged?

---

## Open Data Landscape

**Government data**:
- Official statistics offices
- Agency-specific data releases
- Freedom of information responses
- Quality varies widely

**International organisations**:
- Standardised cross-country data
- Quality controls in place
- May lag real-time
- Coverage gaps for some countries

**Research data**:
- Academic data repositories
- Replication data
- Often requires technical skill to use

**Platform data** (limited):
- Transparency reports
- Ad archives
- Research API access
- Heavily restricted

---

## Data Quality Indicators

**Strong data source**:
- Clear methodology documentation
- Regular updates on known schedule
- Error correction process
- Independent verification possible
- Long track record

**Medium quality**:
- Some documentation
- Irregular updates
- Limited verification possible
- Known but acknowledged limitations

**Weak source**:
- No methodology documentation
- Irregular or unexplained changes
- No correction process
- Contradicts other sources without explanation

---

## Open Data Limits

**What open data doesn't solve**:
- Data can be technically available but practically inaccessible
- Raw data requires expertise to use
- Availability doesn't guarantee quality
- Some important data isn't collected
- Privacy considerations limit some data

**What's often not open**:
- Platform data (restricted access)
- Real-time data (delays for quality control)
- Sensitive categories (privacy protected)
- Proprietary data (commercial restrictions)

---

## Stop Rule

Stop data search when:
- **Data found**: Authoritative source answers the question
- **Data doesn't exist**: Not collected, accept limitation
- **Access restricted**: Consider whether FOI or research access possible
- **Quality too low**: Available data can't answer question reliably

## Key Takeaway

Open data enables verification and accountability when it exists and is quality. But availability varies, quality varies, and technical accessibility matters. Know where to find authoritative sources, how to evaluate their quality, and when to acknowledge data limits.
