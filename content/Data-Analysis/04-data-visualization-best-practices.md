## Purpose

You'll learn to detect visual manipulation of data—and create honest visualizations yourself.

---

## Scenario

A chart supports a dramatic claim. Before accepting the visual argument, you need to assess whether the visualization is honest. You have:

- **Time available**: 5 minutes to evaluate
- **Stakes**: Visual manipulation is persuasive precisely because it's fast
- **Data access**: The visualization, possibly underlying data
- **Constraint**: Visuals bypass analytical thinking

---

## Task

Produce three outputs:

1. **Assessment**: Is this visualization honest or manipulative?
2. **Confidence level**: Low / Medium / High
3. **Next action**: Trust the visual, investigate the data, or dismiss?

---

## Method: Visualization Evaluation

### Start here: Check the axes

- Does Y-axis start at zero? (If not, why?)
- Are axes labeled clearly?
- Is scale consistent?

**Most common manipulation**: Truncated Y-axis making small differences look huge.

### Step 2: Check the comparison

- Are things being compared fairly?
- Same time periods?
- Adjusted for population/inflation/etc. when needed?

### Step 3: Check the visual design

- Do visual elements (area, volume) accurately represent data?
- Are 3D effects distorting perception?
- Does design emphasize some data over others?

---

## Common Visualization Manipulations

**Truncated Y-axis**:
- Y-axis doesn't start at zero
- Makes small changes look dramatic
- Sometimes legitimate, often manipulative

**Inconsistent scales**:
- Comparing things with different scales
- Cherry-picked time periods
- Mixing absolute and relative

**Visual distortion**:
- 3D charts distorting perception
- Area/volume proportions wrong
- Color emphasis directing attention

**Missing context**:
- No baseline or comparison
- No uncertainty shown
- Misleading labels

---

## Honest Visualization Principles

**For evaluation and creation**:
- Y-axis at zero for bar charts (usually)
- Clear, accurate labels
- Consistent scales in comparisons
- Uncertainty shown when relevant
- No distorting visual effects
- Context provided

**When non-zero axis is OK**:
- Line charts showing variation
- When zero is meaningless for the data
- When clearly labeled and not deceptive

---

## Evidence Ladder

**Strong signal** (manipulative visualization):
- Truncated axis without justification
- Obvious cherry-picking of timeframe
- Visual elements don't match data proportions
- Missing crucial context

**Medium signal** (questionable):
- Some axis issues but labeled
- Could be poor design vs intentional manipulation
- Unusual choices without explanation

**Weak signal** (likely acceptable):
- You don't like the conclusion
- Unusual but justified choices
- Different from how you'd design it

---

## Stop Rule

Stop visualization analysis when:
- **Clear manipulation**: Dismiss and possibly debunk
- **Visualization checks out**: Honest design, trust it
- **Need underlying data**: Go to the data, not the visual
- **Stakes too low**: Not worth deep analysis

## Key Takeaway

Visualizations are arguments. They can be honest or manipulative. Check: Does Y-axis start at zero? Are comparisons fair? Do visual elements match data proportions? A good visualization makes data clearer; a manipulative one makes falsehood look true.
